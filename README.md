# ABA SISSA — CHUT !

Page officielle de l’album **CHUT !**, préparée pour GitHub Pages.

Site public : https://fakabox.github.io/ABA-SISSA/

## Mise à jour facile

Les titres, plateformes, réseaux sociaux et informations sur le prochain album sont regroupés dans `app/album-data.ts`.

Pour ajouter un extrait, placez son fichier MP3 dans `public/audio/`, puis renseignez son chemin dans la piste correspondante.

## Publication

Chaque envoi sur la branche `main` déclenche automatiquement la publication GitHub Pages.
